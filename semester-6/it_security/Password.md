
## Requirements
- Minimal Length: 15-20
- Möglichst großes [[Alphabet]]
- Username sollte nicht als substring enthalten sein
- Nutzer sollten es ändern können (möglichst sicher)
- Password expiration
- Prevent reuse of previous passwords
- Keine time-based password expiration

> [!question]- Wieso keine time-based password expiration?
> Führt in Praxis dazu, dass am Ende einfach ein Counter ans Password angehängt wird
> Wenn jemand das Grundschema rausfindet - ist es sehr einfach auf das aktuelle zu schließen
