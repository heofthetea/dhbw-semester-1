[[Hash-Funktion]]

> [!warning] Apple/Google pay sind nur digitalisierte Plastikkarten - Zahlen passiert über die Bank.
> Paypal ist sonderfall

- Visa/Mastercard (die Anbieter) stellen Tokens aus: Ein Token kann für 1-5 Transaktionen verwenden
- Per NFC/Magnetband wird auf dem Host-Gerät eine Kopie der Kartennummer erstellt
	- darüber wird dann per Internet mit dem Server geredet?

> [!hint] Ein Token ist einfach ein [[Hash]] aus Account Number, CVS, Besitzer, etc.
> Dadurch werden die Bezahlvorgänge dann realisiert (auch online etc)

### Anforderungen für Apple/Google Pay
- Biometrisch versichert
- funktioniert über Host Card Emulation und Tokenization
