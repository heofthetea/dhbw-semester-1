> [[Neural Network]], das aus einer Kaskade aus vollvernetzten Schichten besteht


> [!hint] = Es gibt keine Verbindungen über Schichten hinweg.

- de-facto Standard für [[Neural Network]]s, die meisten anderen kinda died out or add more on top of this
## Eigenschaften
- Input Layer + $L$ Schichten
- Input durchläuft Netzwerk stur von vorne nach hinten
	- => keine Shortcuts/Zyklen
- Nichtlineare Aktivierung der [[Neuron|Neuronen]]
