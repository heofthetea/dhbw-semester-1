[[Bedingte Wahrscheinlichkeit]]
$$p(\vec{x}|\omega_{i})$$
alternativ:
$$L(\omega_i|\vec{x})$$

- klassenabhängige point-[[Verteilungsfunktion]] von x
	- => Likelihood is a distribution-function over $x$ => $p(x_{obs}|\omega_{i})$ is a fixed value for an observed value $x_{obs}$

> "wie wahrscheinlich (likely) ist das Feature $x$ in der Klasse $\omega$?"

> [!hint] Wird immer benötigt (s. [[Minimax]]/[[Neyman-Pearson Klassifikator]])
