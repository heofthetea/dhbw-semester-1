> essentially gigantic [[Hash Map|Hash Maps]]

- used to store large data that makes no sense to store relationally
- accessible via [[HTTP]]
- very performant (like [[Hash Map]])
- example: CouchDB, [[Graphdatenbank]]


### workings
 - Access durch [[PRIMARY KEY Constraint|Primary Key]] -> identifyer
- only CUD operations - read/querying has to be handled a layer up
